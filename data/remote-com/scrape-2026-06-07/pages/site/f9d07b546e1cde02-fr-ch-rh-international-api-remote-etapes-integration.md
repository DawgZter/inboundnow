## Étapes préalables

#### Définissez vos objectifs

Déterminez ce que vous voulez accomplir avec l’API. Pour vous inspirer, vous pouvez jeter un œil à nos exemples et cas d’utilisation . Pour découvrir la liste complète des points de terminaison et champs de données disponibles via l’API, nous vous invitons à consulter notre documentation de référence API .

#### Allouez des ressources en interne

Pour une intégration réussie, vous aurez besoin d’un compte Remote et d’un développeur logiciel pour écrire le code.

#### Fournissez un accès administrateur à votre développeur

Votre développeur logiciel aura besoin d’un accès administrateur à votre compte Remote afin de générer un jeton API. Pour fournir un accès administrateur à votre développeur logiciel sur Remote, merci de cliquer ici .

## Étapes de développement

#### Vérifiez votre accès à l’environnement en mode bac à sable

Vous aurez besoin d’accéder à notre environnement de test pour conduire vos tests sur l’API et valider vos résultats avant de modifier votre entreprise de production. Pour accéder à cet environnement, connectez-vous à votre compte Remote et cliquez sur Integrations (Intégrations) > Remote API (API Remote) > Access API (Accéder à l’API). Attention : pour accéder à cette page, vous devez avoir le rôle d’administrateur de l’entreprise (« company admin ») sur Remote.

#### Créez une entreprise test

Une fois dans l’environnement en mode bac à sable, vous devrez créer l’entreprise qui vous servira de test. Pour créer une entreprise, cliquez sur Sign Up (Inscription) et laissez-vous guider. Surtout, pas d’inquiétude : nous ne vous facturerons rien pour les emplois tests créés pour cette entreprise.

#### Obtenez un jeton d’accès API

Un jeton API permet d’authentifier l’utilisateur, lui permettant ainsi d’envoyer une demande à l’API Remote pour accéder aux données de son entreprise. Vous pouvez générer un jeton API en vous rendant sur Account Preferences (Préférences du compte) > API management (Gestion API) dans votre environnement de test. Retrouvez ici les instructions à suivre. Attention : ce jeton ne fonctionnera que pour les demandes API réalisées au sein de l’environnement en mode bac à sable.

#### Testez une première demande

Maintenant que vous avez votre jeton d’accès, utilisez-le pour tester quelques demandes au sein de l’environnement en mode bac à sable, en suivant cet exemple . Connectez-vous à votre entreprise test et vérifiez que votre demande test a fonctionné.

#### Créez et testez votre intégration

Utilisez nos ressources API pour développeur et notre documentation de référence API pour créer et tester votre intégration à Remote en toute simplicité. Si vous avez besoin d’une assistance technique pendant la phase de développement, nous vous invitons à contacter notre équipe à l’adresse api-support@remote.com .

#### Déployez votre intégration à la production

Après avoir vérifié que vos demandes API fonctionnent comme prévu, vous pouvez générer un jeton de production et modifier le chemin d’accès à vos demandes pour commencer à envoyer des demandes à votre entreprise de production. Retrouvez plus de détails sur ces étapes ici .

## Questions fréquentes

L’interface API Remote est-elle fiable ?

Oui. L’API fait l’objet de contrôles, de tests et d’itérations en continu.

Y a-t-il des coûts associés à l’utilisation de l’API Remote ?

Non. À l’heure actuelle, vous n’avez rien à débourser pour utiliser notre API Remote.

En tant que client, est-il obligatoire de créer une intégration avec Remote ?

Non. L’API Remote est un avantage gratuit, destiné aux clients axés sur la technologie qui souhaitent créer des flux de travail ou des automatisations sur mesure, et bien plus encore. Nous voulons que nos clients prennent connaissance en détail de nos exigences relatives à l’intégration, aux points de terminaison et aux cas d’utilisation avant de décider de construire une intégration avec Remote.

Que puis-je faire avec l’API Remote ?

Les possibilités sont infinies. Voici quelques exemples de ce que nous pouvons accomplir.

Synchronisez les données de vos employés avec votre SIRH favori – Bénéficiez d’une vue centralisée des données de l’ensemble de votre équipe, indépendamment du lieu, afin de générer des rapports utiles.

Consolidez vos données de rémunération et vos rapports – Intégrez les dernières données relatives à la rémunération des employés de Remote aux rapports de votre entreprise afin d’obtenir des informations de meilleure qualité.

Automatisez l’intégration des employés – Gagnez du temps et évitez les retards d’intégration en ajoutant vos nouvelles recrues à la plateforme de Remote en un seul clic.

Et encore, tout ceci n’est qu’un pâle aperçu de ce que vous pourrez réaliser avec l’API Remote. Si vous êtes en quête d’inspiration, nous vous invitons à parcourir ces cas d’utilisation : vous y trouverez certainement des idées pour vous lancer !

Dans un premier temps, nous aimerions commencer avec un nombre réduit de points de terminaison. Est-ce possible ?

Oui. Nous avons développé l’API Remote de façon à ce qu’elle s’adapte autant que possible à vos besoins.

Existe-t-il un environnement en mode bac à sable pour que nos développeurs puissent réaliser leurs tests ?

Oui. Un environnement en mode bac à sable est à votre disposition pour conduire des tests sur l’API et valider vos résultats avant de modifier votre entreprise de production.

Pour accéder à l’environnement en mode bac à sable :

- Connectez-vous à votre compte Remote.

- Cliquez sur Integrations (Intégrations) > Remote API (API Remote) > Access API (Accéder à l’API). Un lien vers l’environnement en mode bac à sable vous y attend.

Attention : pour accéder à cette page, vous devez avoir le rôle « company admin » (administrateur de l’entreprise) sur Remote.

Une fois dans l’environnement en mode bac à sable, vous devrez créer l’entreprise qui vous servira de test. Pour créer une entreprise, cliquez sur Sign Up (Inscription) et laissez-vous guider. Surtout, pas d’inquiétude : nous ne vous facturerons rien pour les emplois tests créés pour cette entreprise.

Enfin, générez un jeton API. Un jeton API permet d’authentifier l’utilisateur, lui permettant ainsi d’envoyer une demande à l’API Remote pour accéder aux données de son entreprise. Vous pouvez générer un jeton API en vous rendant sur Account Preferences (Préférences du compte) > API management (Gestion API) dans votre environnement de test. Attention : ce jeton ne fonctionnera que pour les demandes API réalisées au sein de l’environnement en mode bac à sable.

Combien de jetons API un client peut-il détenir à la fois ?

Chaque utilisateur ayant le rôle d’administrateur de l’entreprise peut détenir un seul jeton à la fois. Le jeton n’a pas de date d’expiration. Si vous n’avez plus besoin du jeton, vous pouvez l’annuler.

Y a-t-il des limitations à l’API Remote que nous devrions connaitre ?

L’API Remote limite le nombre de demandes authentifiées à 20 par minute. Nous travaillons en continu pour ajouter de nouveaux points de terminaison à l’API Remote afin que nos clients puissent réaliser tous leurs objectifs d’automatisation. Par exemple, des points de terminaison pour accéder aux données relatives aux congés et aux dépenses via l’API seront bientôt disponibles ! En attendant, si vous avez besoin d’un point de terminaison que nous ne proposons pas encore, vous pouvez le solliciter ici .

Qui soutient nos équipes responsables de la création, l’entretien et l’utilisation de l’intégration ?

Si vous avez des questions ou rencontrez des problèmes techniques au cours de votre développement API, merci d’envoyer un e-mail à api-support@remote.com . Afin de veiller à la cohérence du tri des demandes, notre assistance s’effectue uniquement par e-mail pour l’instant.

Comment participer à d’autres opportunités de marketing avec Remote ?

Notre équipe dédiée apporte son assistance à nos clients pour leurs opportunités de co-marketing en cours. Si vous souhaitez discuter de vos idées et établir un plan, merci de contacter notre équipe à l’adresse api-marketing@remote.com . .
