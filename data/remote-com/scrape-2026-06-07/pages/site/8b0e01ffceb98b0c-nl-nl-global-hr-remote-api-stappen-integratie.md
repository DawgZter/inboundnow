## Stappen voor development

#### Zorgen dat je toegang hebt tot de sandbox

Je hebt toegang tot onze testomgeving nodig om te experimenteren met de API en resultaten te valideren, voordat je wijzigingen aanbrengt aan je productie-account. Voor toegang tot de sandbox log je in op je Remote-account en ga je naar Integraties > Remote API > Toegang tot de API. Let op: Je moet de rol 'bedrijfsbeheerder' in Remote hebben om deze pagina te kunnen bekijken.

#### Een testbedrijf aanmaken

Als je in de sandbox-omgeving bent, moet je een bedrijf aanmaken waar je mee kunt gaan testen. Klik op Aanmelden en navigeer door de aanmeldingsflow om een bedrijf aan te maken. Er worden geen kosten in rekening gebracht voor testwerknemers die je voor het fictieve bedrijf aanmaakt.

#### Een API-toegangstoken ontvangen

Een API-token is een token die gebruikers verifieert en het gebruikers mogelijk maakt om een verzoek in te dienen bij de Remote API voor toegang tot gegevens voor hun bedrijf. Je kunt een API-token genereren door in je testomgeving naar Accountvoorkeuren > API-beheer te gaan en deze instructies te volgen. Houd er rekening mee dat de token alleen werkt voor API-verzoeken die in de sandbox-omgeving worden gedaan.

#### Een testverzoek uitvoeren

Nu je een toegangstoken hebt, kun je wat verzoeken naar de sandbox-omgeving sturen volgens dit voorbeeld. Log in op je testbedrijf en bevestig dat je testverzoek is gelukt.

#### Je integratie ontwikkelen en testen

Gebruik onze API-developerbronnen en API-referentiedocumentatie om je naadloze integratie met Remote te ontwikkelen en testen. Voor technische support tijdens de ontwikkelingsfase kun je contact opnemen met ons team via api-support@remote.com .

#### Je integratie omzetten naar productie

Als je zeker weet dat je API-verzoeken naar verwachting werken, kun je een productietoken genereren en het pad voor je verzoeken wijzigen om verzoeken naar je productiebedrijf te versturen. Meer details over deze stappen vind je hier .

## Veelgestelde vragen

Is de Remote API betrouwbaar?

Ja. De API wordt continue gemonitord, getest en verbeterd.

Zijn er kosten verbonden aan het gebruik van de Remote API?

Nee. Er zijn momenteel geen kosten verbonden aan het gebruik van de Remote API.

Ben ik als klant verplicht om een integratie met Remote te ontwikkelen?

Nee. De Remote API is een voordeel voor tech-first klanten die workflows en automatiseringen op maat willen maken. We willen dat onze klanten onze vereisten voor integratie, eindpunten en use cases goed doornemen, voordat ze besluiten of ze een integratie willen ontwikkelen met Remote.

Wat kan ik met de Remote API?

De mogelijkheden zijn eindeloos. Hier zijn een paar voorbeelden van wat je allemaal kunt doen:

Werknemersgegevens synchroniseren met de HRIS van je voorkeur: Bekijk in één oogopslag de gegevens van al je werknemers, ongeacht waar ze zich bevinden, en maak handige rapporten.

Salarisgegevens en -rapportage samenvoegen: Integreer salarisgegevens van Remote in je bedrijfsrapporten voor extra inzichten.

De onboarding van werknemers automatiseren: Bespaar tijd en vermijd vertragingen in de onboarding door nieuwe werknemers met één klik toe te voegen aan het Remote-platform.

En dit is maar een kleine greep van wat er mogelijk is met de Remote API. Bekijk deze use cases voor meer ideeën en inspiratie om aan de slag te gaan.

We willen graag eerst beginnen met een kleine set eindpunten, kan dat?

Ja. We hebben de Remote API ontwikkeld om zo flexibel mogelijk te zijn voor wat jij nodig hebt.

Is er een sandbox-omgeving waarin onze developers kunnen testen?

Ja. Er is een sandbox-omgeving beschikbaar als je wilt experimenteren met de API en resultaten wilt valideren voordat je wijzigingen aanbrengt aan je productie-account.

Toegang tot de sandbox-omgeving:

- Log in op je Remote-account.

- Ga naar Integraties > Remote API > Toegang tot de API. Hier vind je een link naar de sandbox-omgeving.

Let op: Je moet de rol 'bedrijfsbeheerder' in Remote hebben om deze pagina te kunnen bekijken.

Als je in de sandbox-omgeving bent, moet je een bedrijf aanmaken waar je mee kunt gaan testen. Klik op Aanmelden en navigeer door de aanmeldingsflow om een bedrijf aan te maken. Er worden geen kosten in rekening gebracht voor testwerknemers die je voor het fictieve bedrijf aanmaakt.

Ten slotte kun je een API-token genereren. Een API-token is een token die gebruikers verifieert en het gebruikers mogelijk maakt om een verzoek in te dienen bij de Remote API voor toegang tot gegevens voor hun bedrijf. Je kunt een API-token maken door in je testomgeving naar Accountvoorkeuren > API-beheer te gaan. Houd er rekening mee dat de token alleen werkt voor API-verzoeken die in de sandbox-omgeving worden gedaan.

Hoeveel API-tokens kan een klant tegelijkertijd gebruiken?

Elke gebruiker met de rol bedrijfsbeheerder kan één token tegelijk gebruiken. De token verloopt niet. Als je de token niet meer nodig hebt, dan kun je deze weer intrekken.

Zijn er beperkingen aan de Remote API waarvan we op de hoogte moeten zijn?

De Remote API beperkt het aantal geverifieerde verzoeken tot 20 verzoeken per minuut. We blijven ook voortdurend nieuwe eindpunten aan de Remote API toevoegen, zodat onze klanten al hun automatiseringsdoelen kunnen behalen. Eindpunten voor toegang tot verlof- en onkostengegevens via de API zijn bijvoorbeeld binnenkort beschikbaar! In de tussentijd kun je eindpunten die we niet hebben hier aanvragen .

Wie support onze teams die zich bezighouden met het ontwikkelen, onderhouden en gebruiken van de integratie?

Als je tijdens je API-development vragen hebt of technische problemen ervaart, stuur dan een e-mail naar api-support@remote.com . Momenteel bieden we alleen support via e-mail, om ervoor te zorgen dat elk verzoek op de juiste manier wordt opgepakt.

Hoe kan ik deelnemen aan extra marketingmogelijkheden bij Remote?

Er staat een deskundig team klaar voor ondersteuning bij doorlopende co-marketingkansen voor onze klanten. Je kunt contact opnemen met ons team via api-marketing@remote.com als je een idee of de planning wilt bespreken.
