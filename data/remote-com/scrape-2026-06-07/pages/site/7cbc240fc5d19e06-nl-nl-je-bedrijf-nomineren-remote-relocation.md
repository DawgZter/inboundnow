# Remote Relocation

Wil je je baan bij je huidige bedrijf behouden maar overgeplaatst worden naar een ander land? Wil je dat je bedrijf je overzet van zzp'er naar fulltime werknemer, ook al woon je in een ander land? Remote kan je daarbij helpen.

Je werkgever nomineren

Nomineer je werkgever via het formulier. Remote neemt contact op met je bedrijf over de diensten van Remote Relocation. Deze nominatie is anoniem. Je werkgever krijgt je naam niet te zien, tenzij deze er specifiek naar vraagt.
