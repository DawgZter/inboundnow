## 部门介绍

尽管 Remote 的每个部门都肩负着相同的使命，即帮助客户合规雇佣全球各地的各种人才，但每个团队的具体工作各有侧重。

销售和销售赋能

销售团队协助雇主注册全球雇佣事宜。

销售团队负责响应客户咨询，并主动挖掘能够从全球人才库中获益的企业。为践行我们的“透明”价值理念，我们提供公平价格保证。销售团队帮助客户了解解决全球招聘难题的重要性。

销售赋能团队确保销售团队获得所需的资源、产品更新及培训支持。

销售赋能团队确保相关内容成功创建，且可由销售团队获取和轻松使用。当潜在客户提出疑问时，他们负责处理咨询和问题，并协助销售代表对接运营团队。

法务

为内部团队提供支持，确保全球雇佣合法合规。

该团队为所有部门提供全方位咨询支持，尤其擅长处理合同法和劳动法相关事宜。他们负责培训所有员工，并在团队成员遇到疑问时提供专业支持。

国际运营

化解全球雇佣的繁杂，让人才与机遇畅通无阻。

该团队肩负我们的核心使命：实现合规招聘全球人才的目标。他们负责设立和管理运营实体，确保我们在所有运营国家/地区都具备合法运营资质。

人事

人力资源团队致力于打造创新性人才战略，提升员工体验并推动业务绩效。我们构建并赋能高效能团队，将 Remote 打造成多元包容且激励人心的工作场所。

作为 Remote 的前瞻性创新者，我们致力于推动卓越运营和高效能文化。通过战略性运用人工智能和数据洞察，我们重塑员工体验，赋能领导者，以培育责任担当、主人翁精神及包容性成长。

我们采用实验性方法打造未来产品，确保每位员工获得充分赋能，实现自我成长，并为在 Remote 开启持久而富有影响力的职业生涯做好准备。

产品

拓展 Remote 产品矩阵，提升全球员工的使用体验。

该团队倾听 Remote 运营难题和客户需求，并通过 Remote 产品实现最大程度的自助服务。他们从产品需求和错误报告中提炼洞察，不断迭代优化我们提供的产品。

Remote 金融服务

确保 Remote 成为 100% 合规且值得信赖的金融机构。

作为一家金融服务公司，Remote 依法必须对其所有金融交易进行审核与评估，以确保完全符合法律规定。这正是 Remote 金融服务团队的职责所在。

运营

提供各项服务，确保全球雇佣顺畅无阻。

这支卓越的团队协助客户管理员工的整个雇佣周期，涵盖客户体验、薪资、福利、入职、人员调配以及员工生命周期管理。

设计

提供便捷易用的 Remote 产品，让全球雇佣服务唾手可得。

该团队负责制作精美的文档、图像和界面，帮助客户轻松使用我们的产品！该团队的职责涵盖产品设计、用户体验和品牌设计。

工程

打造 Remote 产品，让全球雇佣变得尽可能简单。

为公司注入资金动力，协助其为更多企业提供全球雇佣服务。
