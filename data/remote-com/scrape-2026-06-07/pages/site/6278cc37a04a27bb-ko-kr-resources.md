# 원격 근무에 관한 전문 자료로 글로벌 HR 관리를 마스터하세요

원격 근무에 관한 리소스와 글로벌 HR 관리 도구를 엄선해서 준비했습니다.

현지 기업처럼 채용하기 위해 필요한 지식

## 전문적인 글로벌 HR 리소스를 활용하여 회사의 성공을 이끄세요

##### 직원 비용 계산기

Remote에서 무료로 제공하는 계산기를 사용하면 새로운 국가에서 직원을 채용하는 데 드는 비용을 알 수 있으므로, 글로벌 팀에 대한 예산을 보다 효과적으로 수립할 수 있습니다.

직원 비용 계산기

##### 기술 스택 통합

Remote은 업계 최고의 지원자 관리 시스템(ATS), HRIS, 급여 통합 기능을 제공하므로, 고객사는 비즈니스와 직원들에게 필요한 플랫폼을 더욱 가치 있게 활용하고 시간을 절약할 수 있습니다.

통합

##### API 문서

Remote의 API 프레임워크를 사용하면 고객에게 글로벌 채용 솔루션을 제공하거나 비즈니스 요구 사항에 맞는 통합 기능을 맞춤 개발할 수 있습니다.

Remote API

##### 전문가에게 배우기

온디맨드 웨비나에서는 글로벌 채용과 관련된 다양한 주제에 대한 패널 토론이 진행됩니다. Remote 전문가와 세계 최고 수준의 파트너가 청중의 실시간 질문에 답하면서 유용한 정보를 알려드립니다.

웨비나

##### 분산 근무 미래에 대한 데이터

Remote의 자체 리서치 보고서 라이브러리에서 글로벌 채용 트렌드, 보상, 복리후생 등에 관한 전 세계 데이터를 확인하실 수 있습니다.

리서치

##### 실제 Remote 고객사의 사례

Remote가 적합한 선택일지 고민되신다면, Remote을 통해 비즈니스 성장을 달성한 실제 고객사의 사례를 확인해 보세요.
