## 구축 전 단계

#### 목표 설정

API를 사용하여 달성하고자 하는 목표를 정하세요. 아이디어를 얻고 싶다면 Remote의 활용 사례와 예시 를 확인해 보세요. API를 통해 제공되는 엔드포인트와 데이터 필드의 전체 목록은 API 참조 문서 에서 확인할 수 있습니다.

#### 내부 리소스 배정

성공적으로 통합하려면 Remote 계정과 함께 코드를 작성할 소프트웨어 개발자가 필요합니다.

#### 개발자에게 관리자 권한 부여

소프트웨어 개발자가 API 토큰을 생성하려면 Remote 계정에 대한 관리자 권한이 있어야 합니다. Remote에서 소프트웨어 개발자에게 관리자 권한을 부여하려면 여기를 클릭 하세요.

## 개발 단계

#### 샌드박스에 액세스할 수 있는지 확인

프로덕션 환경의 회사에 변경 사항을 적용하기 전에 테스트 환경에 액세스하여 API를 실험해 보고 결과를 검증해야 합니다. 샌드박스에 액세스하려면 Remote 계정에 로그인하고 통합(Integrations) > Remote API > API 액세스(Access API)로 이동하세요. 참고로 이 페이지에 액세스하려면 Remote에서 'company admin' 역할을 부여받은 상태여야 합니다.

#### 테스트 회사 생성

샌드박스 환경에 액세스한 후에는 테스트에 사용할 수 있는 회사를 생성해야 합니다. 가입을 클릭하고 회사를 생성하여 가입 과정을 완료합니다. 걱정하지 마세요. 이 회사에 대해 생성하는 테스트 채용에는 어떠한 비용도 부과되지 않습니다.

#### API 액세스 토큰 가져오기

API 토큰은 사용자를 인증하고 해당 사용자가 자신의 회사 데이터를 조회하기 위해 Remote API에 요청할 수 있도록 해줍니다. API 토큰은 테스트 환경에서 계정 기본 설정(Account Preferences) > API 관리(API management)로 이동하고 여기에 나와 있는 지침 을 따라 생성할 수 있습니다. 참고로, 이 토큰은 샌드박스 환경에서 이루어진 API 요청에만 작동합니다.

#### 테스트 요청 실행

액세스 토큰을 가져왔으므로 이를 사용해 여기 에 나와 있는 예시를 참고로 샌드박스 환경에서 요청을 실행해 보세요. 테스트 회사에 로그인하고 테스트 요청이 성공했는지 확인하세요.

#### 통합 구축 및 테스트

API 개발자 리소스 및 API 참조 문서 를 활용해 Remote와의 원활한 통합을 구축하고 테스트하세요. 빌드 단계에서 기술 지원이 필요하시면 api-support@remote.com 으로 문의해 주세요.

#### 통합을 프로덕션 환경에 배포

API 요청이 정상적으로 작동하는 것이 확인되면, 프로덕션 토큰을 생성하고 요청 경로를 변경해 실제 프로덕션 환경의 회사로 요청을 전송할 수 있습니다. 이 단계에 대한 자세한 내용은 여기 에서 확인하세요.

## 시장 출시 단계

#### 통합을 사용하여 팀 지원

팀의 질문과 피드백을 모니터링해 소프트웨어 개발자가 통합을 지속적으로 개선할 수 있도록 도와주세요.

#### Remote와 함께 다양한 마케팅 기회 활용

Remote의 마케팅 팀과 협력해 귀사의 사례를 공유하고, 여러 행사에 함께 참여하며, 귀사의 전문가를 청중에게 소개하는 등 다양한 기회를 누려보세요. Remote와 협업하는 방법에 대해 자세히 알고 싶다면 여기 를 확인하세요.

#### Remote 플랫폼의 최신 소식과 향상된 기능 확인

뉴스레터 를 구독하여 원격 근무 및 글로벌 채용에 대한 최신 정보를 받아보세요. Twitter , LinkedIn , Instagram , YouTube 에서 Remote를 팔로우하고 최신 소식과 업데이트를 받아보세요.

## FAQ

Remote API는 신뢰할 수 있나요?

물론입니다. Remote는 계속해서 API를 모니터링하고 테스트하며 개선하고 있습니다.

Remote API를 사용하는 데 비용이 드나요?

아니요. 현재는 Remote API를 무료로 이용하실 수 있습니다.

Remote를 이용하는 고객이라면 통합을 반드시 구축해야 하나요?

아니요. Remote API는 맞춤형 워크플로, 자동화 등을 구축하려는 기술에 능숙한 고객에게 유용합니다. Remote와의 통합을 구축하기로 결정하기 전에 통합 요건과 엔드포인트, 활용 사례를 충분히 검토하시기를 바랍니다.

Remote API로 할 수 있는 작업은 무엇인가요?

할 수 있는 작업은 무궁무진하며, 그중 몇 가지 예는 다음과 같습니다.

직원 세부 정보를 선호하는 HRIS와 동기화 - 직원의 근무 위치와 관계없이 전체 직원 데이터를 한눈에 확인하여 통찰력 있는 보고서를 만들 수 있습니다.

보상 데이터와 보고서 통합 - 직원 보상에 관한 Remote의 최신 데이터를 회사 보고서에 반영하여 인사이트를 강화하세요.

직원 온보딩 자동화 - 클릭 한 번으로 Remote 플랫폼에 신규 직원을 추가하여 시간을 절약하고 온보딩 지연을 방지할 수 있습니다.

그러나 이는 빙산의 일각에 불과합니다. 다양한 활용 사례를 살펴보고 시작에 도움이 될 만한 아이디어와 영감을 얻어보세요.

먼저 소규모 엔드포인트 세트로 구축을 시작하고 싶은데 가능한가요?

물론입니다. Remote는 고객의 니즈에 맞게 최대한 유연한 설정이 가능하도록 Remote API를 개발했습니다.

개발자들이 시험해 볼 샌드박스 환경이 있나요?

네. 프로덕션 환경의 회사에 변경 사항을 적용하기 전에 API를 실험해 보고 결과를 검증하고자 하는 경우 샌드박스 환경을 사용하실 수 있습니다.

샌드박스 환경에 액세스하려면 다음과 같이 하세요.

- Remote 계정에 로그인합니다.

- 통합(Integrations) > Remote API > API 액세스(Access API)로 이동합니다. 여기서 샌드박스 환경 링크를 확인하실 수 있습니다.

참고로 이 페이지에 액세스하려면 Remote에서 'company admin' 역할을 부여받은 상태여야 합니다.

샌드박스 환경에 액세스한 후에는 테스트에 사용할 수 있는 회사를 생성해야 합니다. 가입을 클릭하고 회사를 생성하여 가입 과정을 완료합니다. 걱정하지 마세요. 이 회사에 대해 생성하는 테스트 채용에는 어떠한 비용도 부과되지 않습니다.

마지막으로 API 토큰을 생성하세요. API 토큰은 사용자를 인증하고 해당 사용자가 자신의 회사 데이터를 조회하기 위해 Remote API에 요청할 수 있도록 해줍니다. API 토큰은 테스트 환경에서 계정 기본 설정(Account Preferences) > API 관리(API management)로 이동해 생성할 수 있습니다. 참고로, 이 토큰은 샌드박스 환경에서 이루어진 API 요청에만 작동합니다.

고객이 한 번에 보유할 수 있는 API 토큰은 몇 개인가요?

각 회사의 admin 사용자는 한 번에 하나의 토큰만 보유할 수 있습니다. 토큰은 만료되지 않으며, 더 이상 필요하지 않은 토큰은 해제할 수 있습니다.

Remote API와 관련해 유의해야 할 제한 사항이 있나요?

Remote API는 인증된 요청 수를 분당 20건으로 제한합니다. 또한 Remote는 고객이 모든 자동화 목표를 달성할 수 있도록 Remote API에 새 엔드포인트를 추가하기 위해 끊임없이 노력하고 있습니다. 예를 들어, API를 통해 휴가 및 경비 데이터에 액세스하기 위한 엔드포인트가 이제 곧 제공될 예정입니다. 필요한 엔드포인트가 아직 제공되지 않은 경우 여기 에서 요청해 주세요.

우리 회사에서 통합을 구축하고 유지하며 사용하는 팀은 누구에게 지원을 요청할 수 있나요?

API 개발 중에 궁금한 사항이 있거나 기술 문제가 발생할 경우 api-support@remote.com 으로 이메일을 보내주세요. 적절한 담당자가 요청을 처리할 수 있도록, 현재는 이메일 지원만 제공하고 있습니다.

Remote와 관련된 추가 마케팅 활동에 참여하려면 어떻게 해야 하나요?

Remote는 고객과 함께 진행하는 공동 마케팅 활동을 지원하기 위해 전담 팀을 운영하고 있습니다. 아이디어나 계획에 대해 논의하고 싶으시면 api-marketing@remote.com 으로 문의해 주세요.
