## 常见问题解答

###### 您是否需要保证金或应计费用？

我们仅在极少数的高风险情况下才会收取预留款。这是一种财务保障措施，确保在即使客户无力向我们付款的情况下，我们仍能支付员工薪资。其他 EOR 服务提供商会收取额外保证金，以提供超过法定最低标准的带薪休假、取消试用期、实施激励计划以及每月计提遣散费。但我们不会收取。

###### 您如何处理货币兑换和外汇 (FX) 汇率？

员工的薪资是以其雇佣协议规定的货币支付。如果薪金（或发票上的任何其他项目）与您的首选结算货币不同，我们将使用 Remote 外汇汇率进行兑换。

Remote 外汇汇率 可能会随时间和货币对不同而变化。该汇率考虑了持有不同货币资产和负债的相关风险、Remote 承担的成本以及行业基准。与其他 EOR 和薪资服务提供商相比， Remote 外汇汇率 极具竞争力。

发票将显示以您首选的计费货币计算的费用。每个项目使用的 Remote 外汇汇率将在我们平台每月的发票明细中显示。

###### Remote 是否有最低员工或合同工数量要求？

您可以使用 Remote 添加和邀请任意数量的直接员工、EOR 员工和合同工，没有最低数量或费用要求。

要为您的直接员工处理薪资，您需要使用我们的全球薪资管理产品。

无论您是招聘 1 名员工，还是 1,000 名员工，我们都将竭诚帮助您扩大规模。

###### Remote 是否收取任何平台、入职或设置费用？

我们的人力资源管理、EOR 和合同工管理产品不收取任何平台、入职或设置费用。您只需根据自身需求，为所使用的产品支付费用。

对于使用我们薪资管理产品的客户，需支付实体注册实施费。此外，还需支付周期性薪资发放服务费，该费用用于支持及时全球薪资支付及安全薪资文件传输所需的基础设施。这确保了关键薪资操作的可靠执行及透明定价。请咨询 Remote 代表，进一步了解该政策如何适用于您的具体情况。

###### 使用 Remote 是否会产生额外费用？

Remote 的定价坚持透明化原则。在某些情况下，可能会产生额外费用，但仅限于您要求特定服务、定制配置或增值功能时。这些费用始终会提前明确告知，并与实际提供的服务直接挂钩，且绝不包含任何隐性加价。您将始终清楚自己支付的费用及其原因。

###### Remote 是否比其他解决方案更实惠？

是。

我们全球所有法律实体均为自主持有，从不依赖第三方来雇佣员工，这有助于避免昂贵的加价，并使我们能够完全控制 EOR 产品的服务质量。

我们的合同工管理产品包含行业领先的公平价格保证，因此您仅需为实际合作的合同工支付费用。使用全球薪资管理，您可以扩大团队规模，而不会因增减员工而受罚——即使您的需求发生变化，也不会产生意外费用。

Remote 的定价体系设计透明且可预测。我们不会抬高基础价格或采用百分比加成，而是将特定服务与支持项目单独列出——您只需为实际使用的产品付费，无需支付其他费用。

###### HR Core 与 Remote 人力资源信息系统 (HRIS) 有何区别？

HR Core 包含在所有 Remote 雇佣和薪资管理解决方案中，为您提供管理员工雇佣周期的基本功能。这包括员工记录、文档管理、休假跟踪、组织结构图、工作流程和内置合规工具。

Remote 人力资源信息系统 (HRIS) 在此基础之上，为发展中的团队提供高级功能支持。通过一体化无缝平台，您将获得更丰富的数据分析、原生集成、可定制工作流，以及贯穿人力资源全流程的精准管控。
